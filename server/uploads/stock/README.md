# Товары из стока

Эта папка содержит изображения товаров для интеграции с каталогом.

## Структура

```
server/uploads/stock/
├── man/
│   ├── FOOTWEAR/
│   │   ├── белые_кроссовки_найк.png
│   │   ├── белые_кроссовки_найк_processed.png  ← Автоматически создается
│   │   └── черные_ботинки_тимберленд.png
│   ├── OUTERWEAR/
│   └── ...
└── woman/
    ├── FOOTWEAR/
    └── ...
```

## Категории

- `OUTERWEAR` - Верхняя одежда (куртки, пальто)
- `INNERWEAR` - Средний слой (свитеры, кардиганы)
- `BODYWEAR` - Базовый слой (футболки, рубашки)
- `FULLBODY` - Цельная одежда (платья, комбинезоны)
- `LEGWEAR` - Брюки, джинсы, юбки
- `FOOTWEAR` - Обувь
- `HEADWEAR` - Головные уборы
- `ACCESSORIES` - Аксессуары (сумки, шарфы)

## Формат названий файлов

Рекомендуемый формат: `цвет_тип_бренд.png`

Примеры:
- `белые_кроссовки_найк.png`
- `черные_ботинки_тимберленд.png`
- `синие_джинсы_левайс.png`

## Импорт

Для импорта товаров в базу данных используйте скрипт:

```bash
# Импорт всех товаров
node server/scripts/import-stock-items.js --all

# Импорт конкретной категории
node server/scripts/import-stock-items.js --gender=man --category=FOOTWEAR

# Импорт для женщин
node server/scripts/import-stock-items.js --gender=woman --all
```

## Автоматическая обработка

Скрипт импорта автоматически:
1. ✅ **Классифицирует** изображение через FastVLM
2. ✅ **Удаляет фон** для чистого отображения на canvas
3. ✅ **Конвертирует в PNG** с прозрачностью
4. ✅ **Извлекает атрибуты** (категория, цвет, материал, стиль)
5. ✅ **Генерирует embedding** вектор для визуального поиска
6. ✅ **Сохраняет обработанное изображение** как `*_processed.png`
7. ✅ **Добавляет в базу данных** с путем к обработанному файлу

### Пример обработки

```
Исходный файл:     белые_кроссовки_найк.jpg
                   ↓
Обработка:         - Удаление фона
                   - Конвертация в PNG
                   - Классификация
                   ↓
Результат:         белые_кроссовки_найк_processed.png
                   (сохраняется в БД)
```

## Требования к изображениям

### Исходные изображения
- Формат: PNG, JPG, JPEG, WEBP
- Рекомендуемый размер: 800x800px или больше
- Качество: высокое (для лучшей классификации)
- Фон: любой (будет автоматически удален)

### Обработанные изображения (автоматически)
- Формат: PNG с прозрачностью
- Фон: удален
- Оптимизация: готово для canvas
- Качество: сохранено

## Преимущества автоматической обработки

1. 🎨 **Чистое отображение** - товары без фона идеально смотрятся на canvas
2. 🚀 **Быстрая интеграция** - не нужно вручную обрабатывать изображения
3. 📦 **Единый формат** - все товары в PNG с прозрачностью
4. 🔍 **Лучшая классификация** - FastVLM анализирует только товар без фона
5. 💾 **Оптимизация** - обработанные файлы готовы для использования
