### План рефакторинга загрузки приложения (Preload)

**Цель:** Изменить логику инициализации приложения для мгновенной отрисовки UI (оптимистичный рендеринг), используя данные из `localStorage`, с последующей фоновой синхронизацией с сервером. Это устранит видимую задержку в ~1.5 секунды при запуске.

---

#### **Проблема:**

Текущая реализация блокирует отрисовку всего интерфейса до тех пор, пока не будет получен ответ от сервера (`historyManager.loadHistoryFromServer()`). Пользователь видит пустой или неактивный интерфейс в течение ~1.5 секунд, даже если актуальные данные уже есть в кэше (`localStorage`).

---

#### **Шаг 1: Рефакторинг `main.ts` — Мгновенная отрисовка**

**Задача:** Разделить инициализацию на два этапа: мгновенная отрисовка из кэша и фоновая синхронизация.

1.  **Файл:** `client/src/main.ts`
2.  **Метод:** `initApp()` (или основная логика в файле).
3.  **Действия:**
    *   Найти текущую последовательность инициализации. Сейчас она выглядит примерно так:
        ```typescript
        // Псевдокод
        await preload(); // Ждем ответа сервера
        uiMenuManager.init(); // Рисуем UI
        ```
    *   Изменить последовательность на следующую:
        1.  **Инициализировать менеджеры:** `historyManager`, `uiMenuManager` и др. `historyManager` в своем конструкторе автоматически загрузит данные из `localStorage`.
        2.  **Мгновенно отрисовать карусель:** Сразу после инициализации вызвать `uiMenuManager.updateHistoryDisplay()`. Это отрисует карусель, используя данные из `localStorage`, которые уже находятся в памяти.
        3.  **Запустить фоновую синхронизацию:** Вызвать `preload()` **без** `await`. Это запустит процесс загрузки данных с сервера в фоне, не блокируя основной поток и уже отрисованный интерфейс.

    *   **Пример нового кода (псевдокод):**
        ```typescript
        // client/src/main.ts

        function initApp() {
          // 1. Инициализация менеджеров (historyManager уже загрузил кэш)
          const historyManager = new HistoryManager();
          const uiMenuManager = new UIMenuManager();
          
          // 2. Мгновенная отрисовка UI из кэша
          uiMenuManager.updateHistoryDisplay();
          
          // 3. Запуск фоновой синхронизации с сервером
          preload(); // БЕЗ await
          
          // ... остальная логика инициализации
        }
        ```

---

#### **Шаг 2: Обеспечение обновления UI после фоновой синхронизации**

**Задача:** Убедиться, что после завершения фоновой загрузки данных с сервера, интерфейс обновится, если данные изменились.

1.  **Файл:** `client/src/modules/history.ts`
2.  **Метод:** `loadHistoryFromServer()`
3.  **Проверка:**
    *   Убедиться, что в конце метода `loadHistoryFromServer` вызывается событие `history:updated`. Текущий код уже это делает, что правильно:
        ```typescript
        window.dispatchEvent(new CustomEvent('history:updated', {
          detail: { source: 'server', itemsCount: this.getFilledCount() }
        }));
        ```

4.  **Файл:** `client/src/main.ts` (или `uiManager.ts`)
5.  **Действия:**
    *   Добавить глобальный слушатель событий, который будет реагировать на `history:updated` и вызывать перерисовку карусели. Это гарантирует, что UI обновится после фоновой синхронизации.
    *   **Пример кода:**
        ```typescript
        // client/src/main.ts

        function setupEventListeners() {
          window.addEventListener('history:updated', (event) => {
            // Перерисовываем карусель, если данные обновились с сервера
            if (event.detail.source === 'server') {
              uiMenuManager.updateHistoryDisplay();
            }
          });
        }

        // Вызвать setupEventListeners() в initApp()
        ```
    *   **Примечание:** Возможно, такой слушатель уже существует. В этом случае нужно просто убедиться, что он работает корректно.

---

#### **Шаг 3: Верификация**

**Задача:** Проверить, что новая логика работает как ожидается.

1.  **Сценарий 1 (С кэшем):**
    *   Запустить приложение, имея данные в `localStorage`.
    *   **Ожидаемый результат:** Карусель с историями и фотографиями появляется мгновенно. Через 1-2 секунды она может "моргнуть" или обновиться, если на сервере были более новые данные (например, изменилось количество лайков).
2.  **Сценарий 2 (Без кэша):**
    *   Очистить `localStorage` через инструменты разработчика.
    *   Запустить приложение.
    *   **Ожидаемый результат:** Приложение запускается мгновенно с пустой каруселью (или с одной пустой карточкой). Через 1.5 секунды карусель заполняется данными, загруженными с сервера.
