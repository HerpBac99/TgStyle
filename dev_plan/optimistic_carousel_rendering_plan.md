### План реализации: Оптимистичный рендеринг карусели истории

**Цель:** Устранить 4-секундную задержку при отображении карусели, реализовав мгновенную отрисовку из кэша `localStorage` с последующим фоновым обновлением данных с сервера.

---

#### **Шаг 1: Модификация `uiManager.ts` для реакции на обновление данных**

**Задача:** Добавить в `uiManager` способность реагировать на событие `history:updated`, которое генерирует `historyManager` после успешной синхронизации с сервером. Это позволит "гидрировать" UI свежими данными.

1.  **Файл для модификации:** `client/src/modules/uiManager.ts`
2.  **Метод:** `setupGlobalEventListeners()`
3.  **Действие:** Добавить слушатель события `history:updated`.

    ```typescript
    // Внутри метода setupGlobalEventListeners
    window.addEventListener('history:updated', this.handleHistoryUpdate.bind(this));
    ```

4.  **Действие:** Создать новый приватный метод `handleHistoryUpdate` для обработки этого события.

    ```typescript
    // Внутри класса UIManager
    /**
     * Обработчик события обновления истории из historyManager.
     * Перерисовывает карусель для отображения свежих данных с сервера.
     */
    private handleHistoryUpdate(event: CustomEvent): void {
      logger.info('History updated event received, re-rendering carousel', { 
        source: event.detail?.source 
      });
      this.updateHistoryDisplay();
    }
    ```

---

#### **Шаг 2: Проверка существующей логики (без изменений)**

**Задача:** Убедиться, что текущая последовательность вызовов в `main.ts` уже обеспечивает первичную отрисовку из кэша.

*   **`historyManager` (конструктор):** Синхронно загружает данные из `localStorage` при создании экземпляра.
*   **`main.ts` (`initialize()`):**
    1.  Вызывает `initializeUI()`, который запускает `uiManager.init()`.
    2.  `uiManager.init()` вызывает `updateHistoryDisplay()`, который **мгновенно отрисовывает карусель с данными из `localStorage`**.
    3.  Параллельно запускается `preloadAppData()`, который инициирует фоновую загрузку `historyManager.loadHistoryFromServer()`.

Эта логика уже корректна и не требует изменений.

---

### Итоговые изменения

*   **Затрагиваемые модули:** Только `client/src/modules/uiManager.ts`.
*   **Ожидаемый пользовательский сценарий:**
    1.  Пользователь открывает приложение.
    2.  Карусель истории отображается **мгновенно** с данными из последнего сеанса.
    3.  Через несколько секунд, после фоновой синхронизации с сервером, карусель незаметно обновляется, отображая любые новые изменения (например, обновленное количество лайков).
*   **Ключевые точки для проверки после реализации:**
    1.  **Мгновенная загрузка:** При перезагрузке страницы карусель должна появляться без задержек.
    2.  **Первый запуск:** При очищенном `localStorage` карусель сначала пуста, затем заполняется после ответа сервера.
    3.  **Обновление данных:** Убедиться, что после фоновой загрузки данные в карусели соответствуют серверным.
