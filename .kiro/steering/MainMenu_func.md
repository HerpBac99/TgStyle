# Главный экран (MainMenu) - Ключевые функции

## Последовательность выполнения методов

### 1. Инициализация приложения
- **Класс**: `TgStyleApp` (main.ts)
- **Метод**: `initialize()`
- **Описание**: Основная точка входа, инициализирует все модули

### 2. Инициализация Telegram WebApp
- **Класс**: `TgStyleApp` (main.ts)
- **Метод**: `initializeTelegram()`
- **Описание**: Настройка Telegram WebApp API, разворачивание приложения

### 3. Инициализация UI
- **Класс**: `TgStyleApp` (main.ts)
- **Метод**: `initializeUI()`
- **Описание**: Вызывает `uiManager.init()` для инициализации всех UI модулей

### 4. Инициализация UI Manager
- **Класс**: `UIManager` (uiManager.ts)
- **Метод**: `init()`
- **Описание**: Инициализирует все UI модули включая uiMenuManager

### 5. Инициализация Menu Manager
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `init()`
- **Описание**: Настраивает навигацию карусели и обработчики событий

### 6. Оптимистичная отрисовка UI
- **Класс**: `TgStyleApp` (main.ts)
- **Метод**: `optimisticUIRender()`
- **Описание**: Мгновенно отрисовывает карусель из localStorage кэша

### 7. Обновление отображения истории
- **Класс**: `UIManager` (uiManager.ts)
- **Метод**: `updateHistoryDisplay()`
- **Описание**: Делегирует в uiMenuManager.updateHistoryDisplay()

### 8. Обновление отображения истории (Menu)
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `updateHistoryDisplay()`
- **Описание**: Создает карусель и позиционирует её

### 9. Создание карт карусели
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `createCarouselCards()`
- **Описание**: Динамически создает карты истории анализов

### 10. Создание одной карты
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `createCard()`
- **Описание**: Создает элемент карты (заполненной или пустой)

### 11. Создание элемента карты
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `createCardElement()`
- **Описание**: Создает базовый div элемент карты

### 12. Создание контента карты
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `createCardContent()`
- **Описание**: Создает контейнер для содержимого карты

### 13. Настройка заполненной карты
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `setupFilledCard()`
- **Описание**: Добавляет изображение, лайки, share кнопку к карте анализа

### 14. Создание компонента лайков
- **Класс**: `AnalysisLikesService` (AnalysisLikesService.ts)
- **Метод**: `createLikeComponent()`
- **Описание**: Создает кнопку лайка с счетчиком для карусели

### 15. Создание кнопки share
- **Класс**: `SharingService` (SharingService.ts)
- **Метод**: `createShareButton()`
- **Описание**: Создает кнопку поделиться для карусели

### 16. Позиционирование карусели
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `positionCarousel()`
- **Описание**: Устанавливает позицию карусели для отображения центральной карты

### 17. Загрузка изображений карт
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `loadVisibleCardImages()`
- **Описание**: Прогрессивная загрузка изображений для видимых карт

### 18. Обработка клика по пустой карте
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `handleHistoryCellClick()`
- **Описание**: Проверяет лимиты и открывает камеру для нового анализа

### 19. Обработка клика по кнопке камеры
- **Класс**: `UIAnalysisManager` (uiAnalysis.ts)
- **Метод**: `handleCameraButtonClick()`
- **Описание**: Открывает камеру/галерею через CameraManager

### 20. Захват фото
- **Класс**: `CameraManager` (camera.ts)
- **Метод**: `capturePhoto()`
- **Описание**: Создает input[type="file"] для выбора фото из камеры/галереи

### 21. Обработка захвата фото
- **Класс**: `UIAnalysisManager` (uiAnalysis.ts)
- **Метод**: `handlePhotoCaptured()`
- **Описание**: Показывает экран анализа с выбором темы

### 22. Показ экрана анализа
- **Класс**: `UIAnalysisManager` (uiAnalysis.ts)
- **Метод**: `showFullscreenPreview()`
- **Описание**: Отображает фото и карточки тем для выбора

### 23. Создание карточек тем
- **Класс**: `UIAnalysisManager` (uiAnalysis.ts)
- **Метод**: `createThemeCards()`
- **Описание**: Создает интерактивные карточки тем анализа

### 24. Выбор темы анализа
- **Класс**: `UIAnalysisManager` (uiAnalysis.ts)
- **Метод**: `selectTheme()`
- **Описание**: Обрабатывает выбор темы и запускает анализ

### 25. Анализ изображения
- **Класс**: `AnalysisManager` (analysis.ts)
- **Метод**: `analyzeImage()`
- **Описание**: Отправляет фото на сервер для AI анализа

### 26. Показ результата анализа
- **Класс**: `UIAnalysisManager` (uiAnalysis.ts)
- **Метод**: `showAnalysisResult()`
- **Описание**: Отображает текст анализа с каскадной анимацией

### 27. Парсинг текста анализа
- **Класс**: `UIAnalysisManager` (uiAnalysis.ts)
- **Метод**: `parseAnalysisText()`
- **Описание**: Разбивает текст на блоки для анимации

### 28. Настройка кнопок результата
- **Класс**: `UIAnalysisManager` (uiAnalysis.ts)
- **Метод**: `setupResultButtons()`
- **Описание**: Подключает обработчики кнопок закрыть, поделиться, рекомендации

### 29. Создание лайков для результата
- **Класс**: `AnalysisLikesService` (AnalysisLikesService.ts)
- **Метод**: `createLikeComponent()`
- **Описание**: Создает кнопку лайка для экрана результата

### 30. Создание share для результата
- **Класс**: `SharingService` (SharingService.ts)
- **Метод**: `createShareButton()`
- **Описание**: Создает кнопку поделиться для экрана результата

### 31. Обработка лайка
- **Класс**: `AnalysisLikesService` (AnalysisLikesService.ts)
- **Метод**: `toggleLike()`
- **Описание**: Переключает лайк с оптимистичным обновлением UI

### 32. Обработка sharing
- **Класс**: `SharingService` (SharingService.ts)
- **Метод**: `share()`
- **Описание**: Делится анализом через Web Share API или Telegram

### 33. Показ сохраненного анализа
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `showSavedAnalysis()`
- **Описание**: Отображает полноэкранный просмотр анализа из истории

### 34. Настройка свайп-управления
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `setupCarouselSwipe()`
- **Описание**: Настраивает touch события для навигации по карусели

### 35. Обработка долгого нажатия
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `startLongPress()`
- **Описание**: Активирует режим удаления элемента истории

### 36. Создание кнопки удаления
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `createDeleteButton()`
- **Описание**: Создает кнопку удаления с SVG иконкой

### 37. Обработка удаления
- **Класс**: `UIMenuManager` (uiMenu.ts)
- **Метод**: `handleDeleteClick()`
- **Описание**: Показывает подтверждение и удаляет элемент истории

### 38. Закрытие экрана анализа
- **Класс**: `UIAnalysisManager` (uiAnalysis.ts)
- **Метод**: `closePreview()`
- **Описание**: Закрывает экран анализа и обновляет историю

### 39. Завершение инициализации
- **Класс**: `TgStyleApp` (main.ts)
- **Метод**: `completeInitialization()`
- **Описание**: Вызывает Telegram WebApp ready() - UI становится видимым пользователю
