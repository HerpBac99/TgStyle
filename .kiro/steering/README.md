## Ключевые концепции

### Singleton паттерн
Все менеджеры экспортируются как экземпляры:
```typescript
export const wardrobeManager = new WardrobeManager();
```

### Оптимистичное обновление
UI обновляется сразу, затем синхронизация с сервером:
```typescript
// 1. Обновить UI
wardrobeItems.unshift(optimisticItem);
renderGrid();

// 2. Синхронизировать с сервером
const serverItem = await wardrobeService.addItem(...);

// 3. Заменить временные данные
wardrobeItems[index] = serverItem;
```

### Событийная система
Связь между модулями через CustomEvent:
```typescript
// Отправка
window.dispatchEvent(new CustomEvent('wardrobe:item-saved', {
  detail: { item }
}));

// Прием
window.addEventListener('wardrobe:item-saved', (e) => {
  const item = e.detail.item;
});
```

### Трехуровневое кэширование
1. **Память** (DataCacheManager) - все данные, мгновенный доступ
2. **localStorage** - первые 30 вещей (без base64)
3. **Браузерный кэш** - изображения

## Метрики производительности

- **Классификация**: 1-2 сек (FastVLM)
- **Удаление фона**: 0.5-1 сек (FastVLM)
- **Сохранение**: 1-2 сек
- **Общее время добавления вещи**: 3-5 сек (было 30+ сек)
- **Загрузка из кэша**: <100ms
- **Загрузка с сервера**: 100-200ms

## Оптимизация изображений

| Этап | Размер | Формат | Цель |
|------|--------|--------|------|
| Оригинал | 5-10 MB | PNG/JPEG | - |
| Для FastVLM | 800px | JPEG 80% | Быстрая передача (~200 KB) |
| Для сохранения | 1200px | PNG | Сохранить прозрачность |
| На сервере | 1200px | PNG/JPEG | Оптимальный размер (500 KB - 1 MB) |

## Частые задачи

### Добавить новое поле в вещь
1. Обновить `db/prisma/schema.prisma`
2. Запустить `cd db && npm run db:push`
3. Обновить типы `client/src/types/wardrobe.ts`
4. Обновить API `server/src/api/wardrobe.js`
5. Обновить UI `client/src/modules/uiModalManager.ts`

### Изменить оптимизацию изображений
- Клиент: `client/src/modules/shared/utils.ts`
- Сервер: `server/src/api/wardrobe.js`

### Отладка проблем
- Логи клиента: `logs/client/`
- Логи сервера: консоль где запущен `python start_app.py`
- Тест FastVLM: `python fastvlm-server/test_classify_clothing.py`
- БД: `cd db && npm run db:studio`
