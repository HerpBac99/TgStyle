# Описание продукта

TgStyle — Telegram Mini App для AI-анализа стиля одежды. Пользователи загружают фото одежды и получают персональные рекомендации по стилю.

## Основные функции

- **Анализ стиля**: Загрузка фото одежды для AI-анализа через FastVLM модель
- **Гардероб**: Хранение и организация вещей с автоматической классификацией
- **Капсулы**: Создание образов из вещей гардероба через canvas-редактор
- **Публичная лента**: Шеринг и просмотр анализов и капсул других пользователей
- **Подписка**: Free (3 анализа/неделю) и Premium (безлимит)

## User Flow

1. Аутентификация через Telegram
2. Фото одежды (камера/галерея)
3. Выбор ситуации для анализа
4. Получение AI-анализа стиля
5. Сохранение в гардероб или создание капсулы
6. Шеринг в публичную ленту

## Платформа

Telegram Mini App с требованием HTTPS для production.
