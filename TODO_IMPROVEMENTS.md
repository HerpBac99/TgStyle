### 6. Добавить Error Boundaries
**Описание:** Централизованная обработка ошибок

**Новый файл:** `modules/shared/ErrorHandler.ts`

```typescript
export class ErrorHandler {
  handle(error: Error, context: string): void {
    logger.error(error, { context });
    
    // Показать пользователю
    if (window.Telegram?.WebApp?.showAlert) {
      window.Telegram.WebApp.showAlert('Произошла ошибка. Попробуйте еще раз.');
    }
    
    // Отправить на сервер (опционально)
    this.reportToServer(error, context);
  }
}
```

**Преимущества:**
- Единая точка обработки
- Лучший UX при ошибках
- Метрики ошибок
