# Очистка таблицы HistoryItem

## Описание
Скрипт `clear-history.js` полностью очищает таблицу `HistoryItem` и связанные с ней данные.

## Что удаляется:
- ✅ Все элементы истории (`HistoryItem`)
- ✅ Все комментарии (`Comment`)
- ✅ Все оценки/рейтинги (`Rating`)

## Запуск скрипта

### Из папки db:
```bash
cd db
node prisma/clear-history.js
```

### Из корня проекта:
```bash
node db/prisma/clear-history.js
```

### С помощью npm скрипта (рекомендуется):
```bash
npm run clear-history
```

## ⚠️ Предупреждения

1. **Действие необратимо** - все данные истории будут удалены навсегда
2. **Влияет на пользователей** - пользователи потеряют свою историю анализов
3. **Каскадное удаление** - автоматически удаляются связанные комментарии и рейтинги

## Безопасность

Скрипт проверяет подключение к базе данных перед выполнением операций.
При ошибке скрипт завершается с кодом 1 и выводит подробную информацию об ошибке.

## Пример вывода

```

Удаляю связанные комментарии...
✅ Удалено комментариев: 15
Удаляю связанные оценки...
✅ Удалено оценок: 8
Удаляю элементы истории...
✅ Удалено элементов истории: 25
🎉 Таблица HistoryItem успешно очищена!
📊 Итого удалено:
   - Элементов истории: 25
   - Комментариев: 15
   - Оценок: 8
```
