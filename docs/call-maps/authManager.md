### `client/src/modules/auth.ts`

Этот модуль отвечает за аутентификацию пользователя через Telegram WebApp и получение данных о его профиле и подписке.

<a name="authenticate"></a>
- **`authenticate()`**: Главный публичный метод, который запускает процесс аутентификации.
    - **`extractUserData()`**: Получает данные пользователя (`id`, `first_name`, `photo_url` и т.д.) из глобального объекта `window.Telegram.WebApp.initDataUnsafe`.
    - **`displayUserProfile()`**: Отображает имя и фото пользователя в интерфейсе, а также информацию о его подписке.
    - **`validateTelegramInitData(initData)`**: Выполняет локальную проверку данных, полученных от Telegram, чтобы убедиться в их целостности перед отправкой на сервер.
    - **`api.authenticate(initData)`**: Отправляет `initData` на бэкенд. Сервер выполняет криптографическую проверку этих данных с помощью токена бота, чтобы убедиться, что они не подделаны, и возвращает в ответ полную информацию о пользователе из БД, включая его подписку.
    - **`displaySubscriptionInfo()`**: (Вызывается внутри `displayUserProfile`) Обновляет UI, отображая тип подписки пользователя (Free/Premium) и количество оставшихся анализов.
