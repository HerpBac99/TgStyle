### `client/src/modules/dataCache.ts`

Этот модуль отвечает за предзагрузку и кэширование данных, таких как элементы гардероба и капсулы, а также изображений, связанных с ними. Это помогает ускорить работу приложения и уменьшить количество запросов к серверу.

<a name="preloadData"></a>
- **`preloadData()`**: Асинхронный публичный метод, который запускает процесс предзагрузки данных.
    - **`Promise.allSettled([...])`**: Параллельно запускает загрузку элементов гардероба и капсул.
        - **`loadWardrobeItems()`**: Загружает список элементов гардероба пользователя с сервера.
            - `api.getWardrobe()`: Отправляет запрос к API для получения данных гардероба.
        - **`loadCapsules()`**: Загружает список капсул пользователя с сервера.
            - `api.getCapsules()`: Отправляет запрос к API для получения данных капсул.
    - **`collectImageUrls()`**: Собирает все уникальные URL изображений из загруженных элементов гардероба, капсул и истории анализов.
        - `historyManager.getAllItems()`: Получает все элементы истории для извлечения путей к фотографиям.
    - **`cacheImages(imageUrls)`**: Асинхронно кэширует собранные изображения в фоне, используя объекты `Image` для предзагрузки. Это делается порциями для контроля нагрузки.
        - `makeAbsoluteUrl(relativeUrl)`: Преобразует относительные URL изображений в абсолютные.
