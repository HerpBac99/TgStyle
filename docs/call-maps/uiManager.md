### `client/src/modules/uiManager.ts`

Это главный модуль-оркестратор для всего пользовательского интерфейса. Он не имеет собственной видимой части, но инициализирует и координирует работу всех остальных UI-модулей.

<a name="constructor"></a>
- **`new UIManager()`**: Конструктор класса, который вызывается при импорте модуля.
    - **`initializeAll()`**: Основной метод, который запускает всю инициализацию UI.
        - `uiMenuManager.init()`: Инициализирует главное меню, историю анализов и связанные с ними обработчики событий (клик, долгое нажатие для удаления).
        - `uiAnalysisManager.init()`: Инициализирует логику, связанную с отображением результатов анализа на главном экране.
        - `uiCoreManager.init()`: Инициализирует базовые элементы UI, такие как модальные окна, toast-уведомления и preloader.
        - `setupTabsListeners()`: Находит все кнопки-табы (`.tab-button`) и назначает им обработчик `handleTabClick` для переключения между экранами (Главная, Гардероб, Капсулы).
        - `setupGlobalEventListeners()`: Устанавливает глобальные обработчики на кастомные события, такие как `analysisStateChange` и `photo:captured`, для реакции на изменения в других частях приложения.

<a name="init"></a>
- **`init()`**: Публичный метод, вызываемый из `main.ts` после базовой инициализации приложения.
    - **`updateHistoryDisplay()`**: Вызывает `uiMenuManager.updateHistoryDisplay()` для обновления и отображения списка истории анализов в левом меню.
