# 📋 Детальный План Внедрения Базы Данных для TgStyle

## 🎯 Обзор Проекта
Внедрение системы базы данных для TgStyle - Telegram Mini App для анализа стиля одежды с функциями хранения истории, комментариев и оценок.

## 📊 Архитектура Решения

### Технологии
- **База данных**: PostgreSQL 15 + Redis 7 (кэширование)
- **ORM**: Prisma (уже настроен в проекте)
- **Backend**: Node.js + Express
- **Frontend**: TypeScript + Vite
- **Контейнеризация**: Docker Compose

### Схема Базы Данных

#### Основные таблицы:
1. **users** - Пользователи Telegram с лимитами подписок
2. **history_items** - История анализов (миграция из localStorage)
3. **ratings** - Оценки постов (лайки/дизлайки)
4. **comments** - Комментарии с поддержкой вложенности

### **Этап 3: Backend API Разработка (4-6 дней)**

#### 3.1 Базовые CRUD операции для истории
- [ ] `GET /api/history` - получить историю пользователя
- [ ] `POST /api/history` - сохранить новый анализ
- [ ] `GET /api/history/:id` - детали анализа
- [ ] `DELETE /api/history/:id` - удалить анализ

#### 3.2 API для комментариев
- [ ] `GET /api/history/:id/comments` - комментарии к посту
- [ ] `POST /api/history/:id/comments` - добавить комментарий
- [ ] `PUT /api/comments/:id` - редактировать комментарий
- [ ] `DELETE /api/comments/:id` - удалить комментарий
- [ ] `POST /api/comments/:id/reply` - ответить на комментарий

#### 3.3 API для оценок
- [ ] `POST /api/history/:id/rate` - поставить лайк/дизлайк
- [ ] `DELETE /api/history/:id/rate` - убрать оценку
- [ ] `GET /api/history/:id/rating` - получить рейтинг поста


#### 3.6 API для лимитов и подписок
- [ ] `GET /api/user/limits` - проверить лимиты пользователя
- [ ] `POST /api/user/analyze` - декремент лимита при анализе
- [ ] `POST /api/user/subscription` - купить премиум подписку
