== АРХИТЕКТУРА КЛИЕНТА ==

## Технологический стек
- **Язык**: TypeScript
- **Модульная архитектура**: ES6 модули
- **Telegram WebApp API**: Интеграция с Telegram
- **Локальное хранение**: localStorage для истории

## Структура модулей

### Core модули (src/modules/)
- **auth.ts** - Авторизация через Telegram WebApp
- **api.ts** - Коммуникация с сервером (FastVLM анализ)
- **camera.ts** - Работа с камерой и галереей
- **analysis.ts** - Обработка результатов анализа одежды
- **history.ts** - Управление историей анализов
- **ui.ts** - Пользовательский интерфейс
- **logger.ts** - Система логирования

### Типы (src/types/)
- **telegram.ts** - Типы Telegram WebApp API
- **api.ts** - Типы API запросов/ответов
- **analysis.ts** - Типы результатов анализа

### Утилиты (src/utils/)
- **constants.ts** - Константы приложения
- **helpers.ts** - Вспомогательные функции
- **validation.ts** - Валидация данных
