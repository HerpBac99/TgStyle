# === ВАЖНЫЕ ЗАМЕТКИ ===
# 
# 1. GPU ПАМЯТЬ:
#    - Минимум 12GB для 7B модели в FP16
#    - Рекомендуется 16GB+ для стабильной работы
#    - При нехватке памяти используйте квантизацию (bitsandbytes)
#
# 2. FLASH ATTENTION:
#    - Значительно ускоряет обработку длинных последовательностей
#    - Требует совместимую NVIDIA GPU (Ampere, Ada Lovelace, Hopper)
#    - Установка: pip install flash-attn --no-build-isolation
#
# 3. CUDA ВЕРСИЯ:
#    - Проверьте совместимость: nvidia-smi
#    - CUDA 12.1 рекомендуется для PyTorch 2.5+
#    - Старые GPU могут требовать CUDA 11.8
#
# 4. АЛЬТЕРНАТИВЫ ПРИ ПРОБЛЕМАХ:
#    - Используйте CPU режим (медленно но работает)
#    - Включите gradient_checkpointing для экономии памяти
#    - Уменьшите max_new_tokens в конфигурации
#
# 5. УСТАНОВКА FLASH ATTENTION (опционально):
#    pip install flash-attn --no-build-isolation
#    pip install xformers  # Альтернатива
#
# 6. МОНИТОРИНГ GPU:
#    watch -n 1 nvidia-smi  # Мониторинг использования GPU
